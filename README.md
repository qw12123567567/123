# 设备台账管理系统 V1.1

生产运行无需npm依赖，面向约1000台设备。后端使用Node.js 24与SQLite。详细操作、42项程序验收结果及未完成项目见`验收与待办.md`；云端部署见`deployment/上线说明.md`。当前按用户选择维护本地版，未开通付费公网服务。

## 启动

环境要求：Node.js 24。可双击`start.cmd`在后台启动，关闭启动窗口不会停止服务；电脑关机后本地服务仍会停止。

```powershell
cd C:\Users\Administrator\Documents\Codex\2026-11-07\ni\outputs\device-ledger
.\start.ps1
```

访问 `http://127.0.0.1:4173`。

## 已实现

- 登录限流、管理员 TOTP、HttpOnly 会话、SameSite Cookie、CSRF 校验；
- 首页指标、设备搜索、组合筛选、快捷筛选、分页、详情和软删除；
- 部门递归数据范围、角色操作权限、价格查看/修改/导出三权分离；
- 自定义敏感字段脱敏、合同/发票附件独立授权、附件下载审计；
- 自定义字段草稿、发布、版本记录和回滚；
- 部门、字典、角色权限矩阵、用户列表、提醒中心、审计日志；
- xlsx/xls/CSV 导入、标准 Excel 模板、预览校验、重复策略和 Excel 导出；
- 二维码标签、打印入口、手动备份、每日自动备份与 30 天清理；
- 桌面端工作台和移动端响应式布局。

V1.1新增：修复弹窗选择器与隐藏必填字段阻塞；支持新增时同步上传PDF/Word说明书；用户与角色创建、账号编辑/停用、密码与MFA重置；字段级查看/修改/导出矩阵；维保/校准/报修/领用/借还/调拨/报废记录及第二人审批；自动编号；规则模板草稿发布回滚；个人列配置、字段筛选与导出；数据质量；数据库与私有附件一致性备份和隔离恢复校验。

程序验收使用jsdom触发页面事件并调用真实HTTP接口，已补充条件显隐、公式与附件型字段、异步导出、列宽/顺序拖动、设备回收站、部门配置继承、站内信已读及AES加密备份。浏览器权限设置仍拒绝本机页面自动化，因此不代表浏览器截图、手机或打印验收已完成。邮件尚缺外部账号与密钥；企业平台及异地存储仍待接入，详见`验收与待办.md`。

开发回归：安装开发依赖后运行`npm test`。测试使用独立临时数据目录，不修改正在使用的台账。

## 数据目录

- 数据库：`data/device-ledger.sqlite`
- 私有附件：`data/uploads/`
- 数据库备份：`data/backups/`

附件目录不通过静态服务器暴露，只能经鉴权接口下载。

## 公网部署

1. 将服务监听地址设为内网地址，外部使用 Nginx/Caddy 反向代理；
2. 强制 HTTPS，并在反向代理启用 HSTS、请求体限制与登录限流；
3. 设置 `APP_ENV=production`，并删除或禁用 `/api/demo-mfa`；
4. 数据库和附件目录使用独立磁盘、加密备份及异地副本；
5. 企业部署应接 SMTP/企业微信等消息渠道，并接入病毒扫描；
6. 首次上线后立即修改演示账号密码并关闭不用的账号。

当前版本是可运行的业务 MVP。企业公网正式上线前仍应完成渗透测试、SMTP/企业消息接入、统一身份认证和一次备份恢复演练。
